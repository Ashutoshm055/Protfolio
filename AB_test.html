Welcome to RenderCV!

RenderCV is a LaTeX-based CV/resume version-control and maintenance app. It allows you to create a high-quality CV or resume as a PDF file from a YAML file, with Markdown syntax support and complete control over the LaTeX code. The boilerplate content was inspired by Gayle McDowell.

Quick Guide

  • Each section title is arbitrary and each section contains a list of entries.
  • There are 7 unique entry types: BulletEntry, TextEntry, EducationEntry, ExperienceEntry, NormalEntry, PublicationEntry, and OneLineEntry.
  • Select a section title, pick an entry type, and start writing your section!
  • Here, you can find a comprehensive user guide for RenderCV.
